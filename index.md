# GEEKOM Backup

GEEKOM Backup ist eine privat genutzte Anwendung zur automatisierten Sicherung eines privaten Heimservers.

Die Anwendung speichert ausschließlich verschlüsselte Backup-Dateien im persönlichen Google Drive des Betreibers.

Der Zugriff auf Google Drive erfolgt über die Google Drive API mit der Berechtigung `drive.file`. Dadurch kann die Anwendung nur auf Dateien zugreifen, die sie selbst erstellt oder die ausdrücklich für sie freigegeben wurden.

Die Anwendung wird ausschließlich privat genutzt und steht nicht zur öffentlichen Verwendung zur Verfügung.
